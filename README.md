# OneVP2.0.0

## 動作環境
macOS 14 Sonoma以降  
（Apple silicon、Intel両対応ユニバーサルバイナリ）

わんコメ バージョン : 8.0.7 または 9.0.0以降  
VOICEPEAK バージョン : 1.2.21以降  
にて動作確認済み。古いバージョンでは正しく動作しない可能性があります。  
VOICEPEAKは体験版を使用している場合、また、ライセンスのアクティベートが行われてない状況では正しく動作しません。  
わんコメやVOICEPEAKのアップデート等で仕様変更が入った場合、   
このアプリケーションが動かなくなる可能性があります。

## OneVP上での設定

VOICEPEAKをデフォルト以外の場所にインストールしている場合は、  
起動直後にダイアログが立ち上がるので、VOICEPEAKのアプリケーションを指定してください。  

## わんコメ側の設定

### 読み上げの停止

わんコメ側の読み上げを止める必要があります。  
枠オプション（枠欄の一番右の「…」→「設定」）の「読み上げボリューム」のスライダーを一番左まで寄せて読み上げを切ってください。

<img width="724" height="459" alt="image" src="https://github.com/user-attachments/assets/b256a0c9-77a9-440f-b978-b245607d387f" />

### 連携の設定（⚠︎重要⚠︎ これを設定しないとVOICEPEAKでの読み上げが動きません）

設定の「連携」の「ゆかコネNEO/TRANS-THROUGH」を有効にし、ポート番号をOneVPで設定したポート番号と合わせてください。  
さらにその下の「読み上げ」タブの「読み上げ連携」を有効にして、読み上げボイスを「OneVP」にセットしてください。

### その他の設定
  
「設定」→「読み上げ」タブの「読み上げボリューム」「読み上げ速度」「読み上げピッチ」は使用できません。  
「連携」→「読み上げ」タブの「読み上げボリューム」も使用できません。  
（読み上げボリュームはOneVP側で調整するようにしてください）  
それ以外の設定や機能はおおむね使用できます。

## おまけ機能

話者に「商用可能 6ナレーターセット」「宮舞モカ」「フリモメン」を指定している場合、  
「絵文字で感情/性別を変更」にチェックを入れると、コメント内に特定の絵文字がある場合に  
発生ボイスの感情や性別が変わる機能があります。  

|絵文字|内容|
|---|---|
|😊😢😆😡😶|感情表現が入る|
|👨👩|強制的に絵文字の性別に変わる|
  
その他の話者についてはライセンスを持ってないので対応できませんが、  
ご協力頂ければ対応できる可能性があります。  
このページの最下部に連絡先がありますので、その旨ご連絡ください。  

## 注意点
けっこうな頻度で  「Voicepeakが予期しない理由で終了しました」  
という問題レポート画面が表示されます。VOICEPEAK側の不具合と思われます。  
OKボタンを押してそのまま閉じて頂いて問題ありません。  

VOICEPEAK側の仕様により、読み上げられる最大文字数は130字程度になっています。  
140文字を超えるコメントが来た場合は、140文字以下に切り詰め +「以下略」と読み上げられます（VOICEPEAKの制限によるもの）。  

Lttle Snitchなどのアプリケーションでネットワーク通信を監視するソフトを入れている場合、  
このアプリケーション（OneVP）の外部へのネットワークを遮断してしまうと  
VOICEPEAKでエラーが出て読み上げができない場合があります。  
（VOICEPEAK側に外部へ通信する処理が入っているためです。このアプリケーション自体は外部への通信処理はありません）  

Blackholeなどの仮想オーディオデバイスをお使いの場合は、  
MacOS標準機能の「Audio MIDI設定」アプリで「マルチ出力デバイス」を作成し、  
システムサウンド出力をマルチ出力デバイスに設定するなどの対応が必要になる場合があります。
